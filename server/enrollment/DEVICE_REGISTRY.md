# МОСТ: именованные мобильные клиенты Windows / OpenWrt

Один Gate обслуживает программные и аппаратные Connector. Идентичность определяется подтверждённым публичным ключом устройства, а не адресом, SSID или объектом. Регистрационное имя (`alias`) закрепляется один раз за уже проверенным устройством. Имя является **указателем**, не полномочием и не заменяет проверку криптографической идентичности.

Пример управления на тестовом сервере с отдельной SQLite DB:

```bash
python3 service.py --db ./gate.sqlite3 register-device --alias laptop --platform windows --ticket <ALREADY_VERIFIED_TICKET>
python3 service.py --db ./gate.sqlite3 register-device --alias travel-gate --platform openwrt --ticket <ALREADY_VERIFIED_TICKET>
python3 service.py --db ./gate.sqlite3 devices
python3 service.py --db ./gate.sqlite3 resolve-device --alias laptop
python3 service.py --db ./gate.sqlite3 disable-device --alias laptop
python3 service.py --db ./gate.sqlite3 enable-device --alias laptop
```

Использование в протоколе: «МОСТ laptop» или «МОСТ travel-gate» означает выбор заранее зарегистрированного устройства, а не согласие подключаться к случайному устройству с тем же именем. При `approved` отдельно требуется подтвердить, что обратный порт реально слушает и отвечает нужный хост; при `pending` нужен штатный процесс одобрения; при `offline`/`revoking` подключение не утверждать.

**Безопасность:** названия уникальны без учёта регистра; соответствие привязано к fingerprint ключа; отключённое имя не разрешается; билеты и приватные ключи в списке отсутствуют. Смена ключа или замена оборудования требует отдельной доверенной перерегистрации. Запись в реестре сама по себе не открывает SSH и не выдаёт новую авторизацию. При смене сети и площадки ключ и имя сохраняются.

**Текущее ограничение:** `resolve-device` использует состояние регистрации Gate, а не проверяет фактический TCP/SSH-туннель. Автоматический выбор по имени в административном протоколе и сквозная проверка нового OpenWrt-клиента требуют дальнейшей интеграции и отдельного развёртывания на production.
