# Hermes Connector enrollment broker — experimental

An unprivileged localhost-only Python service accepts PUBLIC ED25519 device keys (`POST /v1/enroll`), returns random tickets, and provides polling (`GET /v1/enroll/{ticket}`). Devices remain pending until a trusted local operator explicitly approves. The operator CLI runs in dry-run mode by default; `--apply` is a privileged production write, only after explicit approval for that particular enrollment. It backs up `authorized_keys`, installs per-key `permitlisten` restrictions, and restores the backup if the database update fails. Rate limits, authenticated HTTPS, revocation of live sessions, and production deployment are not yet implemented. Do not expose HTTP listener publicly or treat device registration as permission without operator approval.
