# Private GitHub updates for the owner

Connector uses `gh.exe` (GitHub CLI) to read private releases directly from `AQiX-space/hermes-bridge`. One-time `gh auth login --web` authenticates the owner's GitHub account; its credentials are managed by gh's local authentication storage. The Connector NEVER contains or prints a shared GitHub token. A release is selected from canonical tags (e.g. `v0.2.0-beta.4`), drafts are excluded, the `HermesBridge.exe` SHA256 digest is verified against GitHub's release metadata, then the embedded updater replaces the EXE with backup/rollback. This is a personal-use feature requiring gh.exe installed and authenticated. Both manual and six-hour checks use this code. Standard release publication must remain restricted to vetted executables; unsigned binaries may still trigger Defender.
