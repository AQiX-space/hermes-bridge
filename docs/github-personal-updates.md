# Public GitHub Releases as sole update source

From 0.2.0-beta.6 onward, Hermes Connector uses GitHub's public HTTPS REST API `https://api.github.com/repos/AQiX-space/hermes-bridge/releases` and the associated `browser_download_url` for released `HermesBridge.exe` binaries. No `gh`, GitHub login, shared token, AQiX mirror, or backend updater server is required. The published asset SHA256 from GitHub metadata is checked before replacing a binary with rollback. **No publisher Authenticode signature yet.** GitHub hosting and hash matching alone do not protect against compromise of the publishing account: signed releases are a remaining security requirement. Nothing in the public repository gives SSH server authorization to a random client.
