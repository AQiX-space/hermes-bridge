# Hermes Connector 0.3 beta.2 — возврат из трея по PIN

ТЗ владельца: постоянный режим не должен превращаться в ловушку: клик **Открыть** или двойной клик по трею должен запросить PIN и вернуть полный режим поддержки/настроек. Начальный PIN `1111`, изменение в меню трея. Подтверждение PIN не отзывает существующее разрешение и не закрывает работающий SSH-туннель.

## Реализация

- PIN — настраиваемый для **текущего пользователя Windows**, от 4 до 12 цифр, хранится только как salted PBKDF2 (120000 итераций) в DPAPI CurrentUser; файл с паролем в открытом виде отсутствует. Ошибочные попытки: блокировка после 5, начально 30 секунд, затем больше, с сохранением состояния после перезапуска. На старых профилях при первом включении постоянного агента создаётся `1111`, интерфейс явно предупреждает о необходимости замены.
- Защищены: возврат из трея в полноценный режим, смена GR1/GR2, аварийное переподключение, отключение автозапуска, повышение прав из постоянного режима. При возврате после успешной проверки PIN выключается HKCU автозапуск, включается полное окно поддержки и сохраняется действующий туннель. Отдельное нажатие **Отключить** вызывает отзыв разрешения.
- Выход и **Отключить доступ** оставлены местному пользователю без PIN. Приложение удалённой поддержки не должно блокировать отзыв согласия или скрытно поддерживать соединение вопреки воле пользователя.
- PIN не заменяет авторизацию Windows/UAC, не обеспечивает защиту от администратора компьютера или процесса, работающего с тем же Windows SID; это защита интерфейса от случайных действий. Начальный общий `1111` небезопасен и предназначен только для первичной настройки; необходимо сменить на уникальный PIN.

## Приёмка

1. Поддержка → постоянный агент → скрыть в трей. Обычный клик **Открыть** и двойной клик показывают PIN. Отмена/неверный PIN оставляет приложение в трее. Верный PIN показывает основное окно и выключает автозапуск, не трогая разрешение МОСТ и туннель.
2. Сменить PIN через трей, проверить отказ старому PIN, персистентность нового после перезапуска и блокировку после 5 неправильных попыток; убедиться, что PIN не попадает в журнал.
3. Проверить, что меню GR и UAC из постоянного режима не позволяют обойти PIN, но **Отключить**/**Выход** остаются доступными владельцу компьютера.
4. Windows CI: `ResidentPinStoreTests.cs`, собранный PE, тест отключения отзыва и повторного подключения. Реальное GUI-тестирование под Alex обязательно до доступного всем автоматического обновления.
